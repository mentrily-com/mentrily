## 2026-08-07 - Accessible Dropdowns and Mobile Menus
**Learning:** Custom dropdown toggles (like profile avatars or chevrons) and mobile hamburger menus in this Next.js app were missing explicit ARIA linking (`aria-controls`, `aria-expanded`, `aria-haspopup`) to their respective content containers (`id`). Screen reader users had no context that these buttons controlled an expandable menu or drawer. Furthermore, they were missing clear focus ring indicators for keyboard navigation.
**Action:** When creating or modifying custom dropdowns or drawer toggles, always ensure the trigger button and content container are explicitly linked using `id` and `aria-controls`, set `aria-haspopup="menu"`, dynamically manage `aria-expanded`, and include a highly visible focus state (e.g., `focus-visible:ring-2 focus-visible:outline-none`).
