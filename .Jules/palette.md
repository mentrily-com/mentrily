## 2024-05-18 - Mobile Menu Accessibility in Navbar\n**Learning:** The `Navbar.tsx` component handles mobile navigation via a `motion.div` drawer that lacks an `id` to associate with the hamburger toggle button. Additionally, interactive toggle buttons lack focus-visible classes for keyboard navigation out of the box.\n**Action:** When adding or modifying interactive UI components like custom dropdown toggles and hamburger menus in this frontend, always explicitly link the trigger button to the drawer container via `id` and `aria-controls`, include `aria-haspopup="menu"`, manage a dynamic `aria-expanded` state tied to their open/close state for screen reader accessibility, and ensure keyboard navigation focus states are styled using Tailwind s `focus-visible` utility classes.
