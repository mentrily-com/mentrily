## 2024-10-24 - Explicitly Link Dropdowns with ARIA Attributes
**Learning:** When implementing custom interactive elements like hamburger menus or dropdowns in this application, they must explicitly link the trigger button to the container using `aria-controls` and an `id`, specify `aria-haspopup="menu"`, and maintain a dynamic `aria-expanded` state tied to the open/close state. Without this explicitly set, screen readers cannot properly announce the relationship or state of these custom dropdowns.
**Action:** For all custom interactive toggles and dropdowns built going forward, make sure to consistently pair these three ARIA attributes (`aria-controls`, `aria-haspopup`, and `aria-expanded`) along with ensuring proper `focus-visible` utility classes for keyboard accessibility.
