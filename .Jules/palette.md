## 2026-07-29 - Mobile Menu Toggle Accessibility Improvements
**Learning:** Found multiple variations of mobile hamburger menu toggles across different layout variants (`LandingNavbar.tsx` vs `Navbar.tsx`). They were missing critical ARIA attributes for screen readers (`aria-label`, `aria-expanded`, `aria-controls`, `aria-haspopup`) and lacked proper `focus-visible` styling for keyboard navigation, making them inaccessible.
**Action:** When implementing or fixing mobile navigation drawers, always ensure the trigger button explicitly links to the drawer container via `id` and `aria-controls`, manages an `aria-expanded` state, and uses Tailwind's `focus-visible:ring-2 focus-visible:outline-none` for visible keyboard focus outlines. Check multiple layout files for similar components in monorepos.
